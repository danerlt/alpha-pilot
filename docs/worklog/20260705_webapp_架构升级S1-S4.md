## S3 · 认证闭环 + 权限门禁（`b879bbb`）

- `useMe/useLogin/useLogout`（`/api/auth/me` 为登录态唯一判据；会话走 httpOnly cookie，前端不存 token —— 后端 B3 落地前 MSW 用 sessionStorage 模拟完整 401 语义）
- RequireAuth 路由守卫（未登录重定向 /login、登录后回原目标页）；登录页接真实 login 流（密码 → 2FA 六位 → 回跳）
- `usePermission()`：矩阵由 `/api/admin/roles` 下发，前端零硬编码；门禁落点：OrderTicket 提交、持仓操作列（无权限显示"只读"）、侧栏后台管理入口、用户卡真实身份+登出
- 实测链路：访问 /positions → 重定向登录 → 2FA → 回 /positions → 登出回登录页 ✓

## 需要老板/运维做的一件事

dev 服务器外层 nginx 加一个 location（带斜杠剥前缀）后，webapp 即可在 dev 环境访问：

```nginx
location /ap-dev-next/ { proxy_pass http://127.0.0.1:3002/; }
```

WS 反代 `/ap-dev/ws` 若尚未配置（Next 前端未用 WS 时可能缺失），需同步加：

```nginx
location /ap-dev/ws { proxy_pass http://127.0.0.1:8001/ws; proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; }
```
