# 前端现代化 P0 · 地基（已完成）

> 路线图见 `docs/superpowers/specs/2026-06-28-frontend-modernization-design.md`；进度见根 `IMPLEMENTATION_PLAN.md`。

## 做了什么
1. **令牌单一化**：`globals.css` 的旧变量（--accent/--bg-0…）全部别名到设计系统 `--ap-*` 单一源；删除背景发光球（shellAmbient）、渐变 body、玻璃拟态；`layout.tsx` 移除两个 ambient div。auth/admin 旧类保留不塌陷（整页重做留 P2）。
2. **lucide-react**：引入并封装 `src/components/ui/Icon.tsx`（沿用参考 Kit 的 `<Icon name>` API）。
3. **UI 组件库** `src/components/ui/`：Card / StatCard / Badge / Dot / Button / RiskBanner / Table / Sparkline / Modal / ConfirmDialog（含 requireText 口令校验，承载 close-all/mainnet 等高危确认）+ 数字/时间格式化 helpers。全部基于 `--ap-*`，数字 JetBrains Mono + tabular-nums。
4. **新应用外壳** `src/components/shell/`：Sidebar(240px：品牌 α / 账户权益摘要 / 8 段导航含未建页"soon"标 / 引擎状态 / 用户登出) + Topbar(标题 + 风控胶囊降级版 OK/风控事件/已暂停 + AUTO 徽章 + 通知红点) 替换原顶部窄导航；窄屏左侧栏变抽屉。`app-shell.tsx` 重写为编排层，拉 account/kill-switch/risk-events，保留 auth 页无壳 + admin 子导航。
5. **vitest 接入** `@vitejs/plugin-react`（解决 Vitest 4 oxc 不转 JSX 的问题），新增 14 个组件单测。

## 为什么
三套 CSS 并存 + 渐变发光球是"丑/AI 化"的根因；先收敛令牌 + 沉淀组件 + 立起左侧栏 shell，作为后续 P1–P5 全部页面的统一地基，零行为改动、零后端改动。

## 如何验证
- `npx tsc --noEmit` 通过；`npm test` 33 passed；`npm run build` 10 页全部静态预渲染成功。
- auth 页仍无壳、admin 子导航保留；后端零改动。
