# 前端单测框架（Vitest）— 第一梯队收尾（2026-06-27）

## TL;DR

补上 worklog 反复提到的工程门禁缺口：**前端零单测**。引入 Vitest + jsdom，覆盖前端最关键的纯逻辑——
`lib/api.ts` 的 envelope 解析（FE-1 修复的核心）与 `lib/auth.ts` 的会话校验。

**结果：19 个前端测试全过，typecheck + build 不受影响，零内网镜像污染。**

## 为什么先补这个

- 第一梯队第 2 块的遗留项；前端此前只有 `tsc + next build` 作门禁，没有任何行为单测。
- `lib/api.ts` 的 envelope 解析 + JWT 头 + 401 自动登出是 FE-1 大修的核心逻辑，值得回归保护。
- `lib/auth.ts` 的 `readStoredSession` 会话校验（坏 JSON / 非法 role / 缺 token / 非数字 id → null）是登录态健壮性的关键。

## 选型

- **Vitest 4 + jsdom**：最小依赖（不引 testing-library，因为测的是纯 TS 逻辑非 React 渲染）。
- `vitest.config.ts` 配 `@/` alias（对齐 tsconfig paths）+ jsdom 环境 + globals。
- package.json 加 `test`(vitest run) / `test:watch` 脚本。
