## 老板复核调整（优先级高于原清单，务必落实）

1. **WP1 急停 → 一步到位**：后端新增**原子急停端点**（closeAll + pause 单事务，部分失败可回滚/明确回执），前端对接并显示分步结果。不走「前端 try/catch 过渡方案」。资金安全最高，作为后端依赖批次的**首个交付**。

4. **【新增 WP18】整站响应式 shell 提级**：移动端需要**看盘 + 操作**，原 F 类暂缓项全部纳入。作为独立工作包，排在核心安全项 WP1–WP3 之后、其余纯前端项之中偏高位置。
5. **切分策略 → 纯前端批次先行**：纯前端可独立交付的 WP 编为**阶段一**尽早落地；依赖后端端点的编为**阶段二**并标清所需接口。
