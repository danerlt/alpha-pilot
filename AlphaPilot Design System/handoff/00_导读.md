## 与仓库现有规范的关系（重要）

**本交付包不覆盖仓库规范，只做补充。** 优先级：

1. 老板明确指示
2. 仓库 `docs/project.md`（工程宪法：分层/命名/API 契约/异常/日志/测试/Git）
3. 仓库 `CLAUDE.md`（环境规则：uv / `src.` 导入 / env 黑白名单 / 自动 push）
4. 本交付包（设计还原与功能规格）

冲突时按上面顺序让步。例如本包描述的接口路径若与 `project.md` 的 controller 分域规则冲突，按 `project.md` 落位。

## 设计源文件

设计稿在本设计项目（导入仓库后建议放 `design/` 或沿用 `AlphaPilot Design System/` 目录）：

```
colors_and_type.css              # 全部设计 tokens（CSS 变量）
ui_kits/web_app/                 # PC Web 控制台（主要交付物）
  index.html                     # 入口：页面路由/场景/Tweaks
  components/shell.jsx           # 侧栏/顶栏/卡片/图标库/PageShell
  components/ai_card.jsx         # AI 决策卡 3 变体
  components/enhancements.jsx    # 流式决策/熔断横幅/命令面板/动效数字/交互曲线
  components/pages.jsx           # 主控台/决策流/持仓/回测/风控/审计
  components/market.jsx          # 行情页（K线/盘口/成交/合约信息）
  components/trade_panel.jsx     # 手动下单 + 守卫预检
  components/ai_chat.jsx         # Pilot AI 对话抽屉
  components/lab.jsx             # 策略实验室（Shadow Mode）
  components/settings.jsx        # 设置（交易所/LLM/通知/账户）
  components/auth.jsx            # 登录/注册/2FA
  components/admin.jsx           # 后台管理（用户/角色权限/管理日志）
ui_kits/mobile_app/              # 移动端原型（远期参考，不在本期路线图）
README.md / SKILL.md             # 品牌语言、视觉规范、文案规则
```

> 设计稿是 **原型级 React（Babel standalone + 内联样式）**，不是可直接引用的生产代码。
> 正确姿势：按 `01_设计系统集成指南.md` 把它**翻译**成仓库的 Next.js + TSX 组件，而不是复制文件。
