# 01 · 设计系统集成指南

目标：把设计稿的视觉系统落进 `frontend/`（Next.js App Router + TSX），成为唯一样式来源。

## 1. 设计 Tokens

`colors_and_type.css` 是权威 token 表。集成方式：

1. 拷贝到 `frontend/src/styles/design-system.css`（仓库已有此文件——**以设计稿版本为准做合并**，保留仓库侧新增的变量）
2. 在 `src/app/layout.tsx` 全局引入
3. 业务代码**只允许引用 CSS 变量**（`var(--ap-*)`），禁止硬编码十六进制色

核心 token 速查：

| 类别 | 变量 | 值 | 用途 |
|------|------|-----|------|
| 背景 | `--ap-bg-0…4` | `#07090F → #1F2533` | 页面→卡片→悬浮 5 级 |
| 前景 | `--ap-fg-1…5` | `#F5F7FB → #3A4256` | 文字 5 级 |
| 语义 | `--ap-mint` | `#00D395` | 盈利/做多/PASS/主按钮 |
| 语义 | `--ap-rose` | `#FF4D6D` | 亏损/做空/REJECT/熔断 |
| 语义 | `--ap-violet` | `#7C5CFF` | AI 专属（决策/推理/Agent） |
| 语义 | `--ap-amber` | `#F0B90B` | 警告/DEGRADE |
| 语义 | `--ap-cyan` | `#22D3EE` | 信息/数据 |
| 字体 | `--ap-font-sans` | Inter + Noto Sans SC | UI 文字 |
| 字体 | `--ap-font-mono` | JetBrains Mono | **所有数字/代码/trace_id** |

**色彩纪律（review 时检查）**：
- 涨跌色只用于真实数值正负，不做装饰
- violet 只出现在 AI 产物上
- 所有数字用 mono 字体 + `font-variant-numeric: tabular-nums`
- 禁用 emoji；图标用 Lucide（`lucide-react`，仓库前端可直接引入）

## 3. 翻译规则

1. **内联样式 → CSS Modules 或沿用仓库现有方案**（`page.module.css` 风格），值全部换成 `var(--ap-*)`
2. mock 数据全部剥离到 API 调用（`src/lib/api.ts` 已有封装）；原型的 `W_MOCK` 形状可作为 TS 接口的起点
3. 设计稿的 Tweaks（场景切换/卡片变体）不进生产；AI 卡片 variant 作为用户偏好存 localStorage
4. 交互状态规范：hover 背景提一级、press `scale(0.98)`、focus 1.5px ring、disabled 40% 透明度
5. 动画统一 `cubic-bezier(0.4,0,0.2,1)` 160–300ms；尊重 `prefers-reduced-motion`

## 4. 布局常量

- 侧栏 240px 固定；顶栏 60px；内容区 padding 24px
- 卡片圆角 12px、内边距 16-18px、卡片间距 20px；hairline `--ap-line-soft`
- 响应式断点 1180px：主控台右栏（事件流）折叠到下方
- 1920×1080 为主设计尺寸，最低支持 1280
