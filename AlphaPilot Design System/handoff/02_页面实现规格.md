# 02 · 页面实现规格

每页给出：路由、布局、数据来源、关键交互、空/异常态。API 细节见 `03_API_差距与新增接口.md`。
全局：所有页面套 `PageShell`（侧栏+顶栏）；顶栏常驻风控状态胶囊（OK/WARN/HALTED 由 WS 实时驱动）。

---

## P1 登录 / 注册（`/login` `/register`，已有骨架）

- 左品牌面板（标语+核心指标）+ 右表单，双栏满屏，无 PageShell
- 登录 → 2FA 6 位逐格输入（自动跳格、全满自动提交）→ 进入主控台
- 注册后落 `pending` 状态，提示"需管理员批准"；管理员在后台批准
- 异常态：密码错误红字提示；2FA 错误清空重输；被停用账户给明确文案

## P2 主控制台（`/`，已有旧版，按设计稿重构）

布局：左主列 + 右事件流（360px，sticky；<1180px 折叠到下方）

| 区块 | 数据 | 交互 |
|------|------|------|
| 熔断/预警横幅 | risk-events + WS | HALTED 红色（可"查看风控日志"/"手动恢复"→resolve API）；WARN 琥珀色可关闭 |
| AI 决策卡（hero） | decisions 最新 + WS 流式事件 | 流式阶段动画（快照→推理→守卫→裁决→执行）；完成展开完整卡；「重放」按钮；卡片 variant 三选一 |
| 账户权益卡 | account 快照序列 | 数字滚动动效；曲线悬停十字光标 tooltip；HALTED 时曲线变 rose |
| 指标磁贴 ×4 | 今日交易/Sharpe/最大回撤/平均持仓 | — |
| 持仓表（精简） | positions | 行点击 → 持仓页 |
| 事件流 | events/catchup + WS | 实时追加；熔断事件置顶红条 |

HALTED 场景联动（必须全部实现）：横幅出现、hero 决策显示被拒、权益曲线变 rose、事件流置顶熔断条、顶栏胶囊变红。

## P3 行情（`/market`，新页面）

布局：自选列表 220px | K线主区 | 右栏 260px（下单+盘口+合约信息）

- 自选列表：价格/涨跌幅实时；持仓中标 violet 圆点
- K线：lightweight-charts；周期 1m–1d；持仓中叠加 SL/TP/入场标线（远离现价的钉在边缘带 ↓）；当前价 cyan 虚线
- AI 解读条：当前 regime 判定 + 一句话解释（复用 regime 服务输出）+ 资金费率/OI 胶囊
- 盘口/成交：WS 深度与逐笔（Binance 代理）
- **手动下单**（OrderTicket）：买卖/限价市价止损/数量百分比/SL/TP/Reduce-Only；提交前调**守卫预检 API**逐项显示 PASS/FAIL，未过禁用按钮；HALTED 时仅允许 Reduce-Only

## P4 AI 决策流（`/decisions`）

- 过滤 tab：全部/已执行/已拦截（guard=PASS 与否）
- 列表 = 决策卡（用户选定的 variant）；首条支持流式重放
- 卡片点击 → 决策详情（完整 features 快照、守卫逐项结果、reasoning 全文、关联订单）

## P5 持仓与订单（`/positions`）

- 顶部 4 磁贴：总持仓/多头/浮盈总计/活跃挂单
- 持仓表（全列）：编辑 SL/TP（弹窗，走守卫预检）、平仓（二次确认）
- 订单簿表：状态 FILLED/WORKING/CANCELED
- 空态：无持仓时给"AI 正在等待入场信号"插画位

## P6 回测与绩效（`/performance`）

- 6 指标磁贴：净收益(vs HODL)/Sharpe/Sortino/最大回撤/胜率/盈亏比
- 策略 vs BTC/ETH HODL 对比曲线（90 天）
- 月度 PnL 柱状图（**零轴基线**，负值向下）
- 交易统计表；按 symbol/策略/触发类型的归因切换（attribution 表已有）

## P7 策略与风控（`/risk`）

- 受限策略集卡片（启停开关 + 适用 regime 标签）
- 硬风控表（只读展示 + 修改走确认弹窗，需 admin 权限，全部落审计日志）
- 交易对管理（symbol_config 表已有）

## P8 策略实验室（`/lab`，新页面）

- 顶部受控进化流水线图示：提案→SHADOW 14d→CANARY→人工批准→LIVE
- 候选卡：变更说明/来源、影子进度条、影子 vs 线上逐项对比（交易数/胜率/净收益/Sharpe/回撤，优者标 ▲）
- 门槛逻辑：影子期 <60% 或表现未达标 → "申请灰度"禁用并说明原因
- 进化历史：promote/rollback/retire 时间线（rollback 标注触发原因）

## P9 审计日志（`/audit`）

- 事件流全量 + 类型过滤（AI/守卫/成交/熔断）
- AI 日报卡（reports API 已有）

## P10 Pilot AI 对话（全局抽屉，⌘J / 顶栏按钮）

- 右侧 400px 抽屉；消息流 + 工具调用轨迹（"查询决策记录 ✓"逐条显示）+ 打字中动画
- SSE 流式回复；快捷问题 chips
- 涉及配置修改的回复给"应用修改"按钮 → 走对应 API + 人工确认弹窗（AI 无权直改硬风控）

## P11 设置（`/settings`，四分区）

- 交易所连接：Binance/Hyperliquid 选卡；**主网/测试网**切换（testnet cyan 提示 / mainnet rose 警告）；API Key/Secret（脱敏显示）；权限校验清单（读取✓/交易✓/**提现必须关**）；测试连接按钮
- AI 模型：提供方选卡（DeepSeek 推荐/OpenAI/Anthropic/自定义）；模型/BaseURL/Key/温度滑块（建议 0.2–0.4）/token/超时；Agent 分工（决策/信号/复盘各自指定模型）
- 通知：Telegram/Discord 渠道开关；按事件订阅（熔断标"关键"）
- 账户偏好：语言/时区；2FA；会话管理；危险区（紧急停止=close-all+暂停引擎，二次确认）

## P12 后台管理（`/admin`，已有骨架，三分区）

- 用户管理：用户表（角色徽章/状态/2FA/最近活跃）；pending 一键批准/拒绝；停用/启用；邀请
- 角色权限：四角色卡（Owner/Admin/Trader/Viewer）+ 权限矩阵（交易/策略/系统三组；Owner 列锁定）
- 管理日志：不可删审计流（audit_log 表已有），系统自动操作（如自动回滚）标 system
